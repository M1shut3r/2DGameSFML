2D Game SFML
============

Windows
-------
1. Extract the zip archive.
2. Run 2DGameSFML.exe.
   Visual Studio is not required. SFML and the Visual C++ runtime DLLs
   are already included in this folder.

Linux
-----
AppImage:
  chmod +x 2DGameSFML-linux-x86_64.AppImage
  ./2DGameSFML-linux-x86_64.AppImage

Tarball:
  tar -xf 2DGameSFML-linux-x86_64.tar.gz
  cd 2DGameSFML-linux-x86_64
  ./2DGameSFML

Controls
--------
- Left click empty space to launch the ball in that direction.
- Gray square is the goal.
- Top-left icons: mute, next track, reset ball.
