# Security Policy

## Supported versions

The latest GitHub Release is the only supported version.

## Reporting a vulnerability

Please do not open a public issue for security problems.

Email **mishuter1@gmail.com** with:

- a short description of the issue
- steps to reproduce
- the affected version or commit

You can also use GitHub's private vulnerability reporting if it is enabled on
this repository.

You should receive a reply within 7 days. If the report is accepted, a fix will
be shipped in the next release when possible.
